# Physical Calculus Visualizer

An interactive React app that animates real-world motion (a car, a thrown
ball, a roller coaster, a rocket, an ocean buoy) alongside its position,
velocity (1st derivative) and acceleration (2nd derivative) graphs, to make
the connection between physical motion and derivatives tangible.

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Build

```bash
npm run build
npm run preview
```

Built with [Vite](https://vite.dev), React, [Tailwind CSS](https://tailwindcss.com) and [lucide-react](https://lucide.dev) icons.
